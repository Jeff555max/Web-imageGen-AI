# 🎨 Web Image Generator AI

Современное веб-приложение для генерации изображений с использованием искусственного интеллекта на базе GPT-5 Image Mini через OpenRouter API.

## ✨ Особенности

- 🤖 **Мультимодальность**: Автоматическое улучшение промптов с помощью GPT-4o-mini через OpenRouter
- 🎭 **11 художественных стилей**: От реалистичного до аниме, от акварели до киберпанка
- 📐 **3 размера изображений**: 1024x1024, 1024x1792 (портрет), 1792x1024 (альбом)
- 📊 **Прогресс в реальном времени**: Отслеживание процесса генерации
- 🖼️ **Встроенный просмотр**: Просмотр и скачивание изображений в том же окне
- 🔄 **Итеративная генерация**: Возможность исправления и дополнения изображений
- 💾 **Быстрое скачивание**: Сохранение изображений в высоком качестве

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- OpenRouter API ключ

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/Jeff555max/Web-imageGen-AI.git
   cd Web-imageGen-AI
   ```

2. **Создайте виртуальное окружение**
   ```bash
   python -m venv venv
   .\venv\Scripts\Activate.ps1  # Windows PowerShell
   # или
   source venv/bin/activate     # Linux/Mac
   ```

3. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения**
   
   Отредактируйте файл `.env` и добавьте ваш OpenRouter API ключ:
   ```env
   OPENROUTER_API_KEY=your_openrouter_api_key_here
   DEBUG=True
   SECRET_KEY=your_secret_key
   IMAGE_WIDTH=1024
   IMAGE_HEIGHT=1024
   ```

5. **Запустите приложение**
   ```bash
   python app.py
   ```

6. **Откройте браузер**
   
   Перейдите по адресу: `http://localhost:5000`

## 🔧 Как использовать

1. **Введите описание** изображения в текстовое поле
2. **Выберите стиль** из выпадающего списка (опционально)
3. **Нажмите "Улучшить промпт"** для автоматической оптимизации (рекомендуется)
4. **Запустите генерацию** и наблюдайте за прогрессом
5. **Просматривайте результат** и скачивайте изображение
6. **Исправляйте или создавайте новые** варианты по желанию

## ⚙️ Настройки

Все настройки находятся в файле `.env`:

- `OPENROUTER_API_KEY` - ваш ключ OpenRouter API
- `DEBUG` - режим отладки (True/False)
- `SECRET_KEY` - секретный ключ Flask
- `IMAGE_WIDTH/HEIGHT` - размер генерируемых изображений


## 📝 Технологии

- **Backend**: Python, Flask, OpenRouter API
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap
- **AI Models**: GPT-5 Image Mini (генерация изображений), GPT-4o-mini (улучшение промптов)
- **Конфигурация**: python-dotenv


## ⚠️ Важные замечания

- Требуется активный OpenRouter API ключ (получить на https://openrouter.ai)
- Генерация изображений потребляет токены согласно тарифам OpenRouter
- Рекомендуется использовать HTTPS в production
- Не забудьте настроить `.env` файл перед запуском
